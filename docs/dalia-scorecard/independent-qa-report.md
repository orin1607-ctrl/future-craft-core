## הערות לבדיקה בדפדפן

- נבדק החלון האמיתי (`ClaimsAiWorkspace`) בגודל טלפון, עם Supabase מדומה, צ׳אט מדומה, קול עם שני קולות עבריים (Asaf + קול Google בלי מגדר בשם) ומיקרופון שמחקה את התוצאות הכפולות של אנדרואיד.
- תוצאות: קול אחד בכל השיחה (לא Asaf), 0 קטעים מוקלטים, לכל היותר מיקרופון אחד פתוח, כל תשובה מוצגת פעם אחת, הצעה ממתינה נשמרת פעם אחת, תיקון קולי באישור נשמר נכון, שיחה כללית + צ׳אט שומרת את כל השיחה (אחרי תיקון 11).
- שתי "תקלות" בדרך היו של סביבת הבדיקה ולא של המערכת (קול מדומה מהיר מדי; תשובה הבאה שנאמרה לפני ששקט של 1.3 שניות שלח את הקודמת) — תוקנו בסביבת הבדיקה.
