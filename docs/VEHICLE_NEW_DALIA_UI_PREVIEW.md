# תצוגת UI — פתיחת רכב חדש (קוד Claude)

**שלב:** תצוגה בלבד · **אין** Migration · **אין** שמירה ל-Supabase · **כרטיס הרכב (VehicleHub) לא השתנה.**

**שליפה ממשרד התחבורה:** מחוברת ל־`vehicle-lookup` (אותו API כמו `/vehicles` ו־`/vehicle-lookup`) — ללא Mock.

## איך לראות במערכת

| מסלול | כתובת (שרת מקומי) |
|--------|-------------------|
| **תצוגת פיתוח** (מומלץ — בלי התחברות) | http://localhost:8080/dev/vehicle-new-dalia |
| **זרימה אמיתית** (דורש התחברות) | http://localhost:8080/vehicles → «רכב חדש» → שלב 1 → «המשך לטופס המלא» |
| **כרטיס רכב קיים** (להשוואה) | http://localhost:8080/dev/vehicle-card |
| **מדריך זרימות** | http://localhost:8080/dev/vehicle-flows |

הרצה:

```bash
npm run dev
```

פורט ברירת מחדל: **8080** (ראה `vite.config.ts`).

## מבנה המסך (7 סעיפים)

1. פרטי רכב — זיהוי, מחלקות דינמיות, תאריכים  
2. בעלות, ליסינג ומימון — **9 מסלולים** + שעבוד / הלוואה לפי מסלול  
3. ביטוחים ורישיונות — חובה, מקיף, צד ג׳, כיסויים, רישיון, טסט, תזכירים  
4. ציוד וכלים מיוחדים  
5. טיפולים ותחזוקה — כולל ענפי תחזוקה לפי שיטה  
6. מסמכים וקבצים — היסטוריה דינמית  
7. סיכום ושמירה — «בדוק נתונים» + «שמור רכב חדש» (תצוגה בלבד)

## שדות בטופס (ספירה)

- **~150+ שמות שדה** (`name=`) בטופס, כולל קידומות לפי מסלול (`op_`, `fl_`, `loan_`, `mandatory_insurance_`, וכו').
- **9 מסלולי בעלות:** ליסינג תפעולי, ליסינג מימוני, הלוואה/מימון, תחזוקה עצמאית, שירות ותחזוקה, בעלות חברה, בעלות פרטית, השכרה, אחר.
- כפתורי «שמור סעיף» — toast + לוג בלבד, **לא** DB.

## מה לא נכלל בשלב זה (מכוון)

- הרחבת טבלת `vehicles` / טבלאות נלוות  
- שמירה אמיתית של שדות חדשים  
- שינוי VehicleHub
