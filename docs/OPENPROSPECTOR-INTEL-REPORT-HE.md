## מה עדיין מוגבל, ולמה
- **פייסבוק ואינסטגרם:**
  - ה־robots.txt של פייסבוק אוסר איסוף אוטומטי בלי אישור בכתב, ואינסטגרם חוסם הכול.
  - גישה מותרת קיימת רק דרך Graph API או Ad Library API של Meta, ודורשת אפליקציה מאומתת והרשאה. **ממתין להרשאה.**
  - לכן לא נאספים עוקבים, "מי עוקב אחרי מי", פוסטים או רשימות חברים.
- **לינקדאין:** התנאים אוסרים איסוף, וה־API פתוח רק לשותפים. **ממתין להרשאה.**
- **יוטיוב:** אפשרי דרך YouTube Data API, בחינם במכסה היומית, אבל דורש מפתח Google ייעודי שאין במערכת. **ממתין לאישורך.**
- **טיקטוק:** ה־Research API פתוח לאקדמיה בלבד. **חסום.**
- **גוגל ומנועי חיפוש:** חיפוש אוטומטי מותר רק דרך API בתשלום. **לא הופעל, דורש אישור עלות.**
- **קבוצות ופורומים:** מאחורי התחברות, ורשימות חברים הן מידע אישי. **לא נאסף.**
- **שירות התעסוקה:** נשאר חסום כפי שסוכם.
- **מה כן נאסף:** קישורי הרשתות של כל חברה נלקחים מהאתר הרשמי שלה ומ־Wikidata, והם מוצגים כאייקונים לחיצים.
