# דוח תיקון UI — חברות ועסקים (Staging)

## 1. מה היה כפול
- זוהתה כפילות של כפתורי AI: כפתור גלובלי פעיל (`cocoAiFab`) יחד עם כפתורי FAB ישנים (`fab-ai`) במסכים פנימיים.
- זוהתה כפילות כרום עליונה במסך אסטרטגיה: Header חדש של ה-Wizard יחד עם פס הקשר/Toolbar גלובלי שיצר שכבה נוספת.

## 2. איזה כפתור AI הוסר
- הכפתור הישן מסוג `fab-ai` הוסר מהתצוגה (Legacy FAB הוסתר באופן גורף ב-CSS).
- נשאר רק הכפתור הפעיל הגלובלי `#cocoAiFab`.

## 3. איזה Header/Toolbar הוסר או תוקן
- פס ה-Global Context Bar הוחרג ממסך `screen-business-strategy` כדי למנוע Header כפול.
- תוקן ה-wrapper של `goScreen` כך שיעביר `opts` הלאה, כדי לא לשבור התנהגות ניווט/גלילה במסכים אחרים.

## 4. האם הגלילה תוקנה
- בוצעו תיקונים שמונעים חסימת מגע וגלילה במסכי הזרימה (בעיקר במסך אסטרטגיה/Builder).
- נוספו בדיקות QA ממוכנות למסכי מובייל + דסקטופ, כולל בדיקת גלילה במסכים: חברות ועסקים, אסטרטגיה, עוזרים, מטרות, פעולות, היסטוריה, דוחות.
- סטטוס סופי לפי הרצת הסקריפט מצוין ב-`report.json` של QA.

## 5. איפה נמצא הכפתור 🌐 צור אתר AI
- הכפתור מופיע בתוך מסך אסטרטגיית שיווק AI, בשלב האישור (אחרי `export` תקין).
- המיקום הוא באזור `exported` בתחתית שלב 5.

## 6. איך משתמשים במערכת שלב אחרי שלב
- כניסה ל-**חברות ועסקים** -> פתיחת **אסטרטגיית שיווק AI**.
- מילוי/אישור פרטים -> **הפעל ניתוח AI** -> מעבר לדוח -> **אישור ושליחה לעוזרים**.
- לחיצה על **🌐 צור אתר AI** -> מעבר דרך 7 שלבי Website Builder.
- סיום Builder שומר Payload ומחזיר למסך העוזרים להמשך טיפול.
- מדריך מלא מפורט נמצא ב-`HOW-TO-BUILD-AI-SITE-HE.md`.

## 7. האם כרגע נבנה אתר אמיתי או רק דמו
- כרגע מדובר ב-**Demo תפעולי**: Wizard עובד, Data זורם, Payload נשמר.
- לא נבנה אתר חי אמיתי ולא מבוצע Deploy אמיתי מתוך ה-Builder.

## 8. האם קיימת Template קבועה
- אין עדיין תבנית פרודקשן קשיחה ואחידה שממנה נבנים דפים חיים.
- קיים מבנה בסיס/טיוטות תוכן, אך לא מנוע template-to-pages מלא.

## 9. מה חסר כדי לבנות אתר אמיתי
- תבנית בסיס קבועה אחת לכל החברות.
- מנוע יצירת עמודים אמיתי (render) על בסיס נתוני AI.
- חיבור כתיבה פעיל ל-CMS/Hosting בסביבת יעד.
- Preview אמיתי לרמת עמודים, אישור משתמש, ורק אז Deploy.
