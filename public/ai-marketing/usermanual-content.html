🚀 התחלה

איך מפעילים: מערכת דליה → מרכז ניהול → ניהול שיווק (Super Admin בלבד).
פיתוח מקומי מלא (AI + סנכרון): npm run ai-marketing:dev
Staging: צפייה + נתונים סטטיים. AI וסנכרון מלא דורשים שרת מקומי.
  1. התחבר כ-Super Admin למערכת דליה.
  2. פתח ניהול שיווק מהתפריט או ממרכז הניהול.
  3. לחץ 🔄 סנכרן לטעינת נתונים מ-Google Sheets, GSC ו-GA4.
  4. ודא ש-OpenAI מחובר (chip ירוק) — ראה «פתרון תקלות» אם לא.
תפקידי אזורים: דשבורד מנהלים (KPI) · SEO (מילים, מודיעין) · תוכן ו-AI (יצירה, מדריכים) · Google (GBP, Ads) · אנליטיקה · אישורים · דוחות.

🤖 עבודה עם AI

  1. עבור למסך הרלוונטי (מנהל AI, מילות מפתח, מפעל תוכן…).
  2. לחץ 🤖 הרץ AI בראש הדף, או בחר פרומפט מ-מדריך AI.
  3. התשובה תופיע בחלון — לא דמו, אלא OpenAI אמיתי (כשהמפתח מוגדר).
כתיבת בקשות טובות: ציין נושא · קהל יעד · פורmat (רשימה/טבלה) · dalia-c.com · אורך (מילים/נקודות).

📅 עבודה יומיומית

  1. בוקר: סנכרן → תדרוך יומי → התראות.
  2. SEO: מנהל AI + מילות מפתח → זהה הזדמנויות.
  3. תוכן: מפעל תוכן → צור טיוטות → מרכז אישורים.
  4. אישור: אשר/דחה/ערוך → נשמר ב-Google Sheets (COCO_UI).
  5. פרסום: מתזמן → WordPress / GBP (לאחר אישור).
  6. ביצועים: דוחות, ROI, KPI — השוואה שבועית.

🔧 פתרון תקלות

AI לא מגיב
① בדוק .env.openai — OPENAI_API_KEY=sk-...
② הרץ: npm run project-001:openai-probe
③ הפעל: npm run ai-marketing:api
④ בדיקת מודולים: npm run ai-marketing:openai-modules-probe
Google Sheets לא מסתנכרן
① הרץ npm run project-001:auth
② לחץ 🔄 סנכרן (דורש ai-marketing:dev)
③ Staging: נתונים סטטיים מ-dashboard.json
Search Console / Analytics ריקים
① הרץ סנכרון מלא
② בדוק חיבור ב-Google Cloud Console
③ ראה integrations/project-001/config.json
API לא עובד
① npm run ai-marketing:api → http://127.0.0.1:8787/api/health
② ודא שאין חסימת firewall
③ Staging: API לא זמין — השתמש בפיתוח מקומי
בדיקה שהכול תקין
npm run ai-marketing:qa-full — 132+ בדיקות UI + API
