# פיילוט Serper – אתרים לחברות צי בלי אתר (STAGING, יבש)

**השאלה:** האם חיפוש בגוגל (דרך Serper) כ**מצביע** מוצא את האתר של חברות צי שאין להן אתר, כשכל אתר נבדק בכלל של מנוע הזיהוי?

**כלל הבדיקה:** אתר נחשב של החברה רק אם מופיעים בו הח.פ., טלפון ידוע או האימייל המדויק שלה.

**הפיילוט לא כותב לטבלאות `nr_*`.** התוצאות נשמרות מקומית ובסכמת הבדיקה `op_test`.

## הפעלה
התיקייה `C:\Users\אליאב\OpenProspector-Backups\serper-pilot` נמצאת מחוץ ל־repo (המאגר ציבורי).

1. **שמירת המפתח:** שמרו אותו בקובץ `.serper-key` בתיקייה הזאת, או במשתנה הסביבה `SERPER_API_KEY`. לא בצ'אט ולא ב־git.
2. **הדגימה:** `sample.json` כבר מוכן. לרענון:
   ```
   supabase db query --linked -o json -f scripts/pilot-serper/export-sample.sql > "C:/Users/אליאב/OpenProspector-Backups/serper-pilot/sample.json"
   ```
3. **ההרצה:** חיפוש אחד לחברה, עד `--limit` חיפושים. ברירת המחדל 1,000, והמקסימום 2,400 (מתוך 2,500 החינמיים).
   ```
   node scripts/pilot-serper/run.mts --data "C:/Users/אליאב/OpenProspector-Backups/serper-pilot" --limit 1000
   ```
   - הרצה חוזרת ממשיכה מאותה נקודה, ולא מחפשת שוב חברה שכבר חופשה.
   - עצירה מיידית אם Serper דוחה את המפתח או שהקרדיט נגמר.
4. **סיכום ל־`op_test.serper_pilot_result`:**
   ```
   node scripts/pilot-serper/load-results.mjs "C:/Users/אליאב/OpenProspector-Backups/serper-pilot"
   ```
